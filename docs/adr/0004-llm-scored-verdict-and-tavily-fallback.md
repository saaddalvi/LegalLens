# LLM-scored Verdict thresholds and Tavily as the web Fallback

The Grader (Gemini) returns a relevance score in [0, 1] for the retrieved Chunks. The Verdict is **correct** at >= 0.7, **incorrect** at <= 0.3, and **ambiguous** in between. These are starting values, to be re-tuned against the golden set in the evaluation (ticket 11). The Fallback is Tavily's general search API (free tier, returns title, URL and extracted snippet, one HTTP call), selected via `WEB_SEARCH_API_KEY`; with no key configured the Fallback yields nothing and the pipeline degrades to Corpus-only or "cannot answer". An incorrect Verdict answers from Fallback sources alone and carries no Citations; ambiguous combines Chunks and sources.

**Amendment (2026-11-18): official sources first.** The Fallback now searches official domains (`gov.in`, `nic.in`, `prsindia.org`, `indiankanoon.org`) first and falls back to the open web, once, only when those return nothing, so it is one HTTP call when official sources answer and two otherwise. This keeps the broad recall ADR 0001 chose over an official-domains-only Fallback, while preferring government pages: an open search for the RTI application fee returned a YouTube video and a Facebook post among its first five results. Snippets are cut to 1,000 characters and passed to the generation prompt fenced as untrusted data, with angle brackets escaped, so a web page cannot pose as instructions. Trust labels are unchanged. Measured on the golden set (2026-11-18, `gemini-3.1-flash-lite`, same model as the previous run): poor-retrieval CRAG accuracy stayed at 80% with one case flipping each way, and English CRAG fell by one case (`en-ir-strike`, which went through the Fallback). Single-case differences, so inconclusive; see the README results.
